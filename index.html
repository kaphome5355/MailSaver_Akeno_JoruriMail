STEP 1 — メール本文を貼り付けて保存

JoruriMailで開いたメールの本文をコピーしてここに貼り付けてください

0 件保存済み

📌 JoruriMailでの操作手順

  1. 1JoruriMailでメールを1通開く
  2. 2本文をCtrl+A（全選択）→ Ctrl+C（コピー）する
  3. 3下の「件名」「日付」を入力し、本文エリアにCtrl+V（貼り付け）する
  4. 4「この本文を保存リストに追加」ボタンを押す
  5. 5次のメールも同様に繰り返す

保存リスト

STEP 2 — 添付ファイルをドロップ

JoruriMailからダウンロードした添付ファイルをここにドロップして紐付けてください

0 件登録済み

📌 添付ファイルのダウンロード手順

  1. 1JoruriMailでメールを開き、添付ファイルのリンクをクリックしてダウンロード
  2. 2ダウンロードされたファイルを下のエリアにドラッグ＆ドロップ
  3. 3対応するメールを「紐付け先」ドロップダウンで選択する
  4. 4添付ファイルがない場合はそのままSTEP 3へ進んでください

STEP 3 — バッチファイルを生成して実行

バッチファイルをダウンロードしてダブルクリックで実行するとデスクトップの「メール」フォルダへ自動整理されます

整理内容の確認

STEP 1・2 の内容がここに表示されます

📌 実行手順

  1. 1下の「バッチファイルを生成（.bat）」ボタンを押す → .bat ファイルがダウンロードされる
  2. 2添付ファイルが ダウンロード・デスクトップ・ドキュメント フォルダのいずれかにあることを確認する
  3. 3ダウンロードされた .bat ファイルをダブルクリックして実行する
  4. 4完了後 「Y」→ Enter でデスクトップの「メール」フォルダが開く
  5. 5元の添付ファイルは削除されません。整理後もダウンロードフォルダ等にそのまま残ります
.zip は自動で再帰展開されます
入れ子になった ZIP も最大20段階まで完全展開します。
.7z / .rar / .tar / .gz 等は 7-Zip をインストールすることで展開できます（未インストール時はコピーのみ）。
